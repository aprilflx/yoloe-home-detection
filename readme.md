项目目标：用 YOLOE 在家庭场景照片上做开放词汇目标检测，评估零样本效果。

环境：Windows + Miniconda3 + Python 3.11 + Ultralytics。

方法：12 张家庭照片，文本提示 ["cup","book","toy","bottle","chair","table"]，记录检测结果。

主要发现：杯子检测好、椅子稳定、竖放书本漏检、books 比 book 检出多、削笔刀误检为杯子等。

结论：YOLOE 对清晰常见物体零样本效果可接受，对姿态特殊/遮挡多/小物体漏检明显，提示词措辞影响检出。

后续可改进：换词对照、低置信度阈值调整、局部微调。
